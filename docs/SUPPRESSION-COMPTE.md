# Supprimer votre compte FouLove

## Depuis l'app (immédiat)

1. Ouvrez FouLove.
2. **Avec une bulle** : touchez l'engrenage sur l'accueil (*Nous*) → **Zone sensible** → **Supprimer mon compte**.
   **Sans bulle** : sur l'écran d'accueil, touchez « … » en haut à droite → **Supprimer mon compte**.
3. Tapez `SUPPRIMER` pour confirmer (et votre code FouLove si vous en avez un).

## Sans l'app

Écrivez à **[ADRESSE E-MAIL DE CONTACT]** depuis l'adresse de votre compte, avec pour objet « Suppression de compte ».
Nous supprimons le compte sous 30 jours au plus, et vous le confirmons par e-mail.

## Ce qui est supprimé

- votre compte (adresse e-mail ou identifiant Google ou Apple) ;
- votre bulle, chez vous deux : appartenance au couple, invitations, messages chiffrés encore en transit ;
- tous les fichiers chiffrés de votre bulle (photos, vidéos, vocaux) et votre sauvegarde chiffrée ;
- vos clés publiques et vos jetons de notification.

Rien n'est conservé, sauf les journaux techniques de nos hébergeurs, qui expirent selon leurs propres règles.
Vos échanges n'ont jamais été lisibles sur nos serveurs : ils n'existaient en clair que sur vos téléphones.
